# Windows 기본 키오스크 2026.11.23.1

- 버전: 2026.11.23.1 / sequence 2026112301.
- 배포 대상: 기본 키오스크의 `/updates/stable.json`.
- 원인: 웹 미리보기의 메뉴는 수정했지만 Windows 배포 채널은 2026.11.20.2에 머물러 있었다.
- 내용: 사진 기준 디카페인 9개 메뉴, 추천 12개 재편성, 휘핑 조절 10개 메뉴,
  얼음 많이, 시럽 추가 문구. 일반·디카페인 사진을 분리한 113개 상품을 포함한다.
- Python/브라우저 실행 환경은 이전 버전과 동일하다. 원본 사진·글꼴·효과음을 함께 제공한다.

## 배포 및 사용

소스의 release.json을 갱신하고 기본 키오스크 전용 브랜치에서 웹과 Windows 전체
패키지를 빌드했다. 업데이트용 파일과 manifest를 먼저 전송하고 서버의 모든 크기·해시를
검증한 뒤 stable.json을 교체한다. 전체 ZIP과 SHA-256 파일도 같은 버전으로 갱신한다.

Windows에서 인터넷 연결 → 기존 설치 폴더의 업데이트.bat → 완료 후 실행.bat 순서로 사용한다.
업데이트는 다운로드·백업·적용 후 종료하며 자동 실행하지 않는다. 업데이트 출력에서
2026.11.23.1을 확인할 수 있다. 새로 받는 전체 ZIP도 동일한 버전이다.

## 검증 범위

- 웹 빌드 및 Windows x64 패키징. 번들 ZIP과 실행 파일 구조 검사.
- 공개 HTTPS의 배포 파일 452개: 전송된 파일 크기·SHA-256 일치.
- 이전 버전 설치 파일을 복제한 Mac 시험 폴더에서 실제 HTTPS로 새 파일을 내려받아
  업데이트 코드를 실행했다. 변경 23개 적용, 재실행 변경 0개.
- 업데이트 후 모든 manifest 파일 해시 일치, 113개 상품·디카페인 9개 확인.
  실행 환경과 별도 설정 파일 보존, 자동 프로그램 실행 없음.
- 새 패키지의 실제 로컬 백엔드와 정적 웹을 실행해 외부 네트워크 요청을 차단한 상태로
  설정 저장 → 디카페인 메뉴 → 얼음 많이·휘핑 제거 → 결제 → 영수증 PNG 생성을 확인.
  외부 요청·실패 요청·브라우저 오류 0개. 로컬 글꼴 로딩·설정 유지 확인.
- 백엔드·업데이터 자동 검사 25개 통과. 앞선 메뉴 변경은 데이터 검사 22개와 화면 검사
  35개를 통과했다.

Mac에서 Windows용 파일과 업데이트 동작을 검증한 결과다. 실제 Windows PC에서의
배치파일 실행·USB 프린터 실물 출력까지 확인한 결과는 아니다.

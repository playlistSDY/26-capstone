# Windows 기본 키오스크 2026.11.23.3

한 메뉴와 주문 전체의 음료 수량 제한을 999개로 통일했다. 수량 버튼은 999에서
증가를 멈추고, 메뉴 추가·동일 옵션 합산·저장 복원·결제 검증은 1000개를 거부한다.
영수증 생성도 999개를 허용한다. 전체 수량은 출력 서버에서 다시 확인하며,
많은 옵션 항목의 전송이 가능하도록 영수증 요청 본문만 최대 4MiB로 제한한다.
수량 999개에 따른 큰 금액이 버튼과 겹치지 않도록 금액 칸을 내용에 맞춰 늘렸다.

## 검증

- 데이터·주문 검사 24개, 백엔드·업데이터 검사 28개 통과.
- 브라우저에서 998→999 증가 후 버튼 비활성화, 옵션 수정·새로고침·결제·출력 요청까지
  수량 유지 확인. 1600×2560 및 1280×800에서 금액·수량·삭제 버튼이 겹치지 않음.
- 공개 기본 웹에서 수량 999개, 증가 버튼 비활성화, 합계 4,495,500원 확인.
- Windows 패키지의 실제 로컬 웹·백엔드를 Mac에서 실행해 외부 연결을 차단한 채
  999개 주문·영수증 PNG 생성·설정 보존 확인. 외부/실패 요청·브라우저 오류 0개.
- 공개 HTTPS 업데이트 파일을 이전 2026.11.23.2 설치 파일에 적용하는 Mac 시험:
  변경 17개, 재실행 변경 0개, 453개 파일 해시 일치, 실행 환경·설정 보존, 자동 실행 없음.
- 전체 ZIP의 CRC·SHA-256과 메뉴 제한 코드를 검증한 뒤 업데이트 채널에 게시한다.

Windows에서는 업데이트.bat 완료 후 실행.bat으로 실행한다. 실제 Windows 배치 실행과
TM-m30 실물 출력 확인을 대신하는 검증은 아니다.

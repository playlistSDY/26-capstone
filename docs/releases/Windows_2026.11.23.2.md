# Windows 기본 키오스크 2026.11.23.2

- 강제 새로고침으로 이전 화면이 사라졌다는 현장 피드백을 반영했다.
- Windows 실행 주소에 appVersion을 넣어 이전 릴리스의 페이지 주소와 구분한다.
- 시작 HTML은 no-store/no-cache로 응답하고 If-Modified-Since가 있어도 본문을 보낸다.
  이미지·글꼴 등 정적 자산의 캐시는 유지한다.
- 얼음을 함께 갈아 만드는 블렌디드 14개 메뉴는 iceAdjustable=false로 고정한다.
  UI에서 얼음 선택을 숨기고 저장·주문 검증에서도 많이/적게/없이를 거부한다.
- 일반 아이스 음료의 얼음 선택과 휘핑 옵션, 업데이트 후 자동 실행 금지 정책은 유지한다.

## 검증

- 데이터·주문 검사 23개, 백엔드·업데이터 검사 27개, 관련 브라우저 검사 6개 통과.
- 시작 HTML의 수정 시각을 고정한 채 내용을 바꾸고 미래 If-Modified-Since를 보내도
  304가 아닌 최신 본문의 200 응답을 확인했다. 정적 파일의 정상 캐시 응답도 확인했다.
- 망고 플랫치노·플레인 요거트·밀크쉐이크의 얼음 옵션 없음, 에이드의 얼음 옵션 유지 확인.
- 새 Windows 패키지의 로컬 백엔드·웹에서 외부 요청을 차단한 주문·영수증 PNG 검사 통과.
  entryCacheDisabled=true, 외부/실패 요청과 브라우저 오류 0건.
- 공개 HTTPS에서 이전 2026.11.23.1 설치 파일에 새 배포를 적용하는 Mac 시험 통과.
  변경 13개, 재실행 변경 0개, 452개 전체 해시 일치, 실행 환경·설정 파일 보존,
  자동 실행 없음. 기본 웹의 블렌디드 얼음 옵션 제거도 공개 주소에서 확인했다.
- 전체 Windows ZIP의 해시·CRC·릴리스 버전·메뉴 데이터와 업데이트 파일을 검증한 뒤 게시한다.

# 비용과 응답 시간 표시

각 답변의 토큰 옆에 대화+TTS 예상 비용과 응답 시간을 표시하고, 패널 하단에는 세션 누적 예상 비용을 표시한다. 이전 완료 세션의 비용도 토큰 요약에 함께 보관한다.

## 가격 기준

2026-11-21에 확인한 OpenAI Standard 공개 가격이다. 금액은 USD이며 100만 토큰 기준이다. 중앙 서버의 order-agent/data/model-pricing.json에서 모델별 단가·검증일·출처를 관리한다.

| 모델·종류 | 입력 | 캐시 입력 | 출력 |
|---|---:|---:|---:|
| GPT-6.2 Sol 텍스트 | $2.00 | $0.10 | $10.00 |
| Realtime 2.1 mini 텍스트 | $0.60 | $0.06 | $2.40 |
| Realtime 2.1 mini 음성 | $10.00 | $0.30 | $20.00 |

[GPT-6.2 Sol 공식 가격](https://developers.openai.com/api/docs/models/gpt-6.2-sol), [Realtime 2.1 mini 공식 가격](https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini).

Sol의 명시적 캐시 쓰기 토큰이 반환되면 30분 보관 기본 단가 $2.50를 사용한다. 272,000 입력 토큰을 초과한 단일 요청에는 입력·캐시 단가 2배, 출력 단가 1.5배를 적용한다. SDK의 요청별 사용량을 각각 계산하므로 짧은 요청 여러 개를 긴 요청 하나로 오인하지 않는다.

캐시 입력은 전체 입력에 포함되므로 일반 입력에서 제외해 중복 과금하지 않는다. TTS는 반환된 텍스트·음성·캐시 토큰 종류를 분리해 계산한다. 각 요청의 비용을 반올림하지 않고 누적한 뒤 화면에 표시할 때만 반올림한다. 가격을 모르는 모델이나 불충분한 음성 토큰 내역은 ‘비용 미집계’로 표시하며, 일부만 집계된 누적치는 +로 구분한다.

표시는 공개 단가로 계산한 예상액이며 청구서 조회 기능이 아니다. 세금·개별 할인·환율·Fast/Batch 등 별도 요금제는 포함하지 않는다. 현 실행 경로의 Standard 토큰 사용량을 기준으로 하며, 외부 유료 도구를 추가하면 별도 비용 계산이 필요하다.

## 응답 시간

화면의 ‘응답 N ms’는 새 발화 전송 시작부터 최종 텍스트 수신까지 브라우저의 단조 시간 performance.now로 측정한다. 네트워크·모델·도구 처리·끼어들기 정리를 포함하고, 이후의 TTS 음성 재생은 포함하지 않는다. 동일 요청 재확인 시 최초 전송 시각을 유지한다.

서버도 각 턴 이벤트에 timing.response_ms와 timing.first_text_ms를 반환한다. 서버 값은 요청 등록부터 최종 이벤트까지의 처리 시간이며, 첫 글자 시간은 첫 text.delta가 있을 때만 기록한다. 브라우저 값과 구분한다.

## 검증

캐시 읽기·쓰기, 장문 요청 할증, 짧은 요청 여러 개, TTS 종류별 계산, 알 수 없는 모델, 반올림 없는 누적, 늦은 응답의 누적 비용 유지와 UI의 ms 표시를 검증한다. Python 98개·웹 단위 테스트 38개를 통과했다.

공개 서버에서 실제 응답의 대화 예상액 $0.015839와 TTS 예상액 $0.0012836이 합산되어 화면에 약 $0.0171로 표시되는 것을 확인했다. 같은 응답의 브라우저 측 지연은 2,600ms, 서버 처리 시간은 1,743ms였다. 이는 검증 한 건의 기록이며 일반 응답의 고정 비용이나 속도가 아니다.

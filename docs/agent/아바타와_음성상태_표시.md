# 에이전트 모드의 점원과 대화 말풍선

2026-11-23. 키오스크 안의 큰 점원 캐릭터와 두 방향의 말풍선으로 대화한다. 별도 채팅 사이드바·대화 내역 버튼·입력 대기 배지는 사용하지 않는다. 하단 텍스트 입력은 STT 대용 개발 도구다. 기본 동작은 계속 에이전트의 직접 주문·수정·결제 화면 이동이다.

## 대화 표현

1. 손님이 말하는 단계에는 점원 말풍선에 ‘듣고 있어요’와 느린 점 애니메이션을 표시한다. 현재 텍스트 대용 입력에서는 타이핑을 이 단계로 표현하며 실제 마이크 수음 기능을 추가한 것은 아니다.
2. 입력을 전송하면 확정된 손님 문장을 파란색 오른쪽 말풍선에 표시한다. 입력 중인 글이나 STT 중간 텍스트는 확정 문장처럼 표시하지 않는다.
3. 점원은 왼쪽의 흰색 말풍선으로 답한다. 테두리·상태 제목·도구 버튼을 줄이고 문장을 중심으로 표시한다.
4. 답변이 오래 걸리면 같은 점원 말풍선에서 짧은 대기 문구를 7초 간격으로 바꾼다. 30초 이상이면 지연을 분명하게 알린다. 실제로 확인하지 않은 메뉴 조회·주문 성공·진행률을 꾸미지 않는다. 대기 문구를 TTS로 추가 낭독하거나 새 모델 요청을 보내지 않는다.
5. 음성 생성 대기 중에도 실제 답변 자막은 유지한다. 음성 재생이 시작된 뒤 실제 출력 크기에 맞춰 입을 움직인다.

원래 대화와 사용량은 개발 검증용 DOM·세션에 유지하지만 제품 화면에 기록 열기 버튼은 없다. 이 표시는 별도의 확인 질문이나 주문 진행 조건을 추가하지 않는다.

## 큰 글씨와 캐릭터

- 캐릭터 폭은 실제 화면 기준으로 데스크톱 180px, 작은 화면 130px이다. 고정 크기 키오스크를 축소한 미리보기에서도 이 크기를 유지한다.
- 두 말풍선의 본문은 실제 화면에서 24px이 되도록 미리보기 배율을 역보정한다. 손님은 진한 파랑·오른쪽 꼬리, 점원은 흰색·왼쪽 꼬리로 구분한다.
- 사용자 제공 `Frame 92.png`를 기준으로 만든 모션 시트와 원본을 `kiosk-web/public/agent/`에 보관한다. 눈 깜빡임·작은 손짓·호흡을 사용하며, 동작 줄이기 설정을 존중한다.
- 입은 Web Audio의 실제 재생 시각과 40ms PCM 크기에 연결된다. 생성·다운로드 중에는 움직이지 않고, 무음·중단·음소거·완료·오류에 맞춰 닫힌다. 음소별 정밀 립싱크는 아니다.

## 배치와 여백

에이전트 모드에서는 홈의 장식용 음료 영역을 점원의 공간으로 쓰고 메뉴 목록 아래, 장바구니 위에 대화 영역을 둔다. 메뉴 종류 탭 바로 아래에는 여백 없이 메뉴가 먼저 보인다. 메뉴는 세 열로 보여 주고 빈 장바구니의 큰 안내 영역은 숨긴다. 실제 메뉴를 담으면 장바구니가 다시 나타난다. 원래 AI 없는 데모는 별도로 유지한다.

하단 전체를 180px 줄이는 고정 공간은 제거했다. 옵션·결제 모달은 원래 높이를 사용하며 점원은 UI 위의 레이어에서 머문다. 적합한 후보 위치를 선택하고 필요하면 캐릭터를 끌거나 방향키로 옮길 수 있다. 캐릭터를 누르면 말풍선을 잠시 접거나 펼친다. 말풍선 배경은 아래 UI의 클릭을 가로막지 않는다.

캐릭터와 말풍선은 고정된 대화 좌표 영역 안에 함께 놓인다. 같은 화면에서 새 문장·TTS 상태·대기 문구·안내 ID가 바뀌어도 위치를 다시 계산하지 않는다. 실제 화면·모달·편집 메뉴·화면 크기 또는 장바구니에 따른 메뉴 하단 영역의 높이가 바뀔 때만 배치를 갱신한다. 대화 영역이 준비되기 전의 위치를 계속 사용하는 문제도 막아 메뉴와 점원 영역이 어긋나지 않도록 한다.

## 입력 어댑터 계약

`AgentChat.voiceInput`은 후속 연결용 `phase=off/listening/speech/transcribing/error`, `partial?` 계약이다. 실제 수음·STT 연결은 이번 범위에 포함하지 않는다. 실제 말소리 감지(`speech`) 또는 현재 텍스트 대용 입력 중일 때 듣기 말풍선을 사용하며, 단순히 세션이 열려 있다는 이유로 상시 듣기 문구를 띄우지 않는다. 최종 STT 문장은 기존 사용자 턴으로 전달한 뒤 손님 말풍선에 표시한다.

## 구현과 검증

- `KioskCompanion.tsx` / `kiosk-companion.css`: 대화 순서·말풍선·고정 좌표·큰 표시·드래그.
- `companionPlacement.ts`: 화면 경계·설명 대상·UI 요소를 고려한 후보 배치.
- `companionFeedback.ts`: 사실에 맞는 대기 문구와 경과 시간.
- `AgentAvatar.tsx`, `agentAudio.ts`, `audioActivity.ts`: 캐릭터 합성·실제 출력에 맞춘 입 움직임.
- `AgentChat.tsx`: 원래 주문·중단·사용량 처리를 유지하며 화면 표현을 연결.

검증은 실제 픽셀 기준 글자·캐릭터 크기, 확정 전후 말풍선 구분, 상시 상태·기록 버튼 없음, 30초 이상 대기 문구 변경, 중복 요청 없음, 새 답변 전후 좌표 유지, 메뉴 대화 영역과 실제 캐릭터 경계 일치, TTS·중단·완료와 기존 주문·결제 흐름을 확인한다. 하드웨어 수음과 실물 결제 시험은 별도다.

2026-11-23 검증 결과: 단위 테스트 44개와 최종 아바타·기본 주문 브라우저 16개, 타입 검사·웹 빌드를 통과했다. 기존 안내·대화 결제·음료·결제·자동 출력 시나리오도 함께 회귀 확인했다. 430px 화면에서 말풍선 본문이 실제 24px, 캐릭터가 130px로 표시되는 것을 측정했다. 30초 이상 대기와 새 답변 뒤에도 좌표가 유지되고, 요청이 중복 전송되지 않는 것을 확인했다. 전송 전에는 듣기 말풍선만, 전송 후에는 손님 문장과 점원 응답이 별도 말풍선으로 나타난다. 메뉴 대화 영역과 캐릭터의 실제 경계가 일치하는 것도 확인했다.

메뉴 하단 배치 수정 후 아바타·대화 결제 브라우저 16개와 웹 빌드를 확인했다. 탭 다음에는 메뉴가 바로 표시되고, 대화 영역은 메뉴 스크롤 밖의 하단에 고정된다. 장바구니가 나타나 영역 위치가 바뀌면 배치를 한 번 갱신하되 새 말풍선만으로 움직이지 않는다.

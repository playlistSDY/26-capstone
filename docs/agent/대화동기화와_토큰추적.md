# 화면 동기화, 끼어들기와 토큰 추적

## 결제 동의

결제수단 화면으로의 이동은 실제 청구가 아니므로, 문맥상 동의 여부는 모델이 판단한다. 고정된 긍정 문자열 목록과 2분 만료 제한은 제거했다. ‘그럼 그렇게 진행해 주시면 돼요’, ‘좋네요 넘어가요’ 등 자연스러운 동의로 넘어간다. 옵션 질문의 동의와 전체 주문 확인은 대화 맥락으로 구별한다. 실제 주문이 변경되면 새 내용으로 확인하며 승인 결과는 여전히 리더기·키오스크가 제공한다.

고객이 끼어들면 낭독을 멈추고 현재 요청을 반영한다. 결제수단 화면으로 이동하는 조건에 낭독·요약 전달 ACK를 사용하지 않는다. 실제 주문 변경을 반영한 뒤 진행하며 같은 요약을 반복 확인하지 않는다.

## 끼어들기

각 중단은 request_id가 가리키는 요청만 취소한다. 아직 등록되지 않은 요청의 중단도 기록해 늦게 도착한 예전 요청의 실행을 막는다. 늦은 중단이 새 요약을 무효화하거나 오래된 응답·오류가 새 UI를 덮어쓰지 않도록 요청 세대를 검사한다. 빠르게 연속 제출한 경우 최신 제출을 우선한다.

대화 이력에는 중간에 실제 출력한 텍스트와 중단 사실을 남겨 ‘그거’ 같은 후속 지시를 이어 갈 수 있게 한다. 완료한 도구 변경은 현재 서버 상태를 기준으로 유지하고 반복 실행하지 않는다. 미완성 함수 호출 메시지는 다음 모델 입력에 넣지 않는다.

## 직접 터치한 조작

키오스크는 메뉴 추가·옵션/수량 변경·삭제·매장/포장·화면·결제 상태·편집 중인 메뉴·카테고리·오버레이 변화를 구조화된 이력으로 보관한다. 최근 24개 이력과 최신 화면을 다음 대화에 보내고 서버는 이벤트 ID로 중복 기록을 막는다. 추가 후 바로 지워 최종 장바구니가 같아져도 조작 내역을 참고할 수 있다.

현재 실제 장바구니와 화면 선택을 과거 대화보다 우선한다. 옵션 창을 열어 둔 채 질문할 수도 있고 ‘이대로 담아줘’에는 편집 중인 실제 선택을 참고한다. 응답 대기 중 직접 수정하면 오래된 답변이 화면을 덮어쓰지 않으며 새 대화로 강제 초기화하지 않는다. 결제 결과는 즉시 안내하고, 일반 터치마다 불필요한 질문·음성을 만들지 않는다. 이는 현재 세션의 맥락 동기화이며 모델 가중치를 학습시키거나 고객별 장기 기억을 만드는 기능은 아니다.

## 토큰 표시

각 답변 아래에는 대화 모델의 입력·출력 토큰과 수신한 TTS 토큰을 작게 표시한다. 패널 하단은 현재 세션의 대화·음성 토큰을 별도로 표시한다. SDK가 반환한 모든 도구 왕복의 사용량을 합산하며, 입력에는 시스템 지침·이력·도구 결과·캐시 입력이 포함된다. 세션 완료 후에는 이전 세션 누적치를 작은 안내로 유지한다.

캐시된 음성을 재생해도 새 API 호출로 중복 집계하지 않는다. 늦게 도착한 음성 사용량이 누적치를 줄이지 않도록 한다. 중단·연결 오류로 제공자가 사용량을 반환하지 않은 부분은 추정하지 않고 ‘일부 중단 요청 미집계’로 표시한다. 대화 토큰과 음성 토큰은 별도 단가로 계산한 뒤 USD 예상 비용을 합산한다. [비용과 응답 시간 표시](비용과_응답시간_표시.md)를 참고한다.

## 화면 배치

가로 1024px 이상은 키오스크와 채팅을 좌우로 배치한다. 그보다 좁으면 같은 작업 영역에서 위아래로 배치하고 세로로 스크롤한다. 상단 네비바는 줄바꿈하고 공통으로 유지한다. 320/430/820/1024/1360px 화면에서 겹침과 가로 잘림을 검증한다.

## 자동 검증

Python 98개, 웹 단위 테스트 38개, 관련 브라우저 시나리오 12개를 검증한다. 음성 안내 중 동의, 늦은 응답, 직접 터치 변경 유지, 세션/개별 토큰, 기존 5종 결제수단과 완료 흐름을 포함한다.

공개 서버의 실제 모델에서도 ‘그럼 그렇게 진행해 주시면 돼요’로 낭독 중인 화면 요약을 확인하고 결제수단 단계로 넘어갔다. 사용량 API에서 실제 대화 세션 30,032토큰, 해당 검사 중 TTS 255토큰을 반환받았다. 이 수치는 그 검사 세션의 기록이며 일반 주문의 예상 사용량이나 비용이 아니다. 390/820/1360px 공개 화면에서 가로 넘침 없음과 입력창 접근도 확인했다.

결제와 기본 옵션의 최신 정책은 [반복 확인을 줄이는 정책](확인_반복을_줄이는_정책.md)을 따른다.

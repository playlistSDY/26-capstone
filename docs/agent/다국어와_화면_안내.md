# 다국어 응대와 메뉴 중앙 안내

기본 키오스크와 AI 키오스크 모두 시작·메뉴·주문·결제 화면 상단에서 한국어,
English, 简体中文, 日本語를 선택할 수 있다. 메뉴 113개의 이름·설명과 옵션·결제
화면 문구를 `kiosk-web/src/ui-translations.json`에서 읽는다. 번역 문구는 OpenAI로
초안을 만들고 주요 화면·카테고리·상태 문구를 보완했다. 메뉴 ID·카테고리 키·
옵션 값·원화 가격과 재고·제약은 번역하지 않는다. 실제 메뉴 정보는 변하지 않는다.

언어 선택은 기기별 localStorage의 `switch.kiosk.language`에 저장한다. 새로고침과
주문 변경 뒤에도 선택 언어를 유지하며 사용자가 상단에서 다시 변경할 수 있다.
기본 키오스크에는 에이전트 UI나 API 의존성을 추가하지 않는다. 해당 변경은
`codex/kiosk-languages-basic` 브랜치에서 별도로 관리한다.

## 에이전트 계약

- 요청: `cart.ui_context.language`에 `ko`, `en`, `zh`, `ja`를 전달한다.
- 응답: 상태의 `language`가 지원 언어라면 화면도 같은 언어로 전환한다.
- `set_language(language)`는 선호 언어만 바꾸며 주문과 결제 확인을 취소하지 않는다.
- 언어 변경 요청이나 분명한 외국어 문장은 선호 언어 변경으로 처리한다. 메뉴명
  한 단어·인용문만으로는 바꾸지 않는다. 변경 이후 다음 대화에서도 유지한다.
- 같은 UI 언어를 반복 전송해도 음성·텍스트로 지정한 새 선호 언어를 덮어쓰지 않는다.
  UI에서 실제로 다른 언어를 고른 경우에는 새 선택을 반영한다.
- `search_menu`는 한국어 이름과 번역된 영어·중국어·일본어 이름을 함께 검색한다.
- 주문 확인·결제 안내·완료 문구도 같은 언어로 구성한다. TTS는 문장을 번역하거나
  재작성하지 않고 원래 언어로 읽는다. 기존 Cedar 음색과 끼어들기 처리는 유지한다.

## 화면 중앙 안내

`guide_ui`로 설명 중인 실제 버튼·메뉴를 표시할 때 가장 가까운 스크롤 영역만
움직인다. 확대·축소된 키오스크의 실제 좌표와 논리 좌표를 변환해 대상의 가운데를
해당 영역 중앙에 맞춘다. 화면 맨 아래 메뉴는 안내 중에만 필요한 아래 여백을
추가해 중앙까지 올리며 안내가 끝나면 원래 여백으로 되돌린다. 전체 페이지나
키오스크 크기는 바꾸지 않는다. 동작 줄이기 설정에서는 애니메이션 없이 이동한다.

## 검증

113개 메뉴의 번역 존재, 원화 금액 보존, 언어 변경 뒤 장바구니·선택·결제 유지,
언어의 다음 요청 전달, 번역 메뉴명 검색, 다국어 주문 확인과 결제 안내를 검증한다.
기본 키오스크의 독립된 실행 화면에서도 언어 변경·주문·결제 흐름을 검사한다.

2026-11-23 확인: 웹 단위 테스트 51개, 에이전트 테스트 120개, 전체 브라우저
테스트 65개 및 기본 키오스크 독립 언어 흐름 1개와 양쪽 빌드가 통과했다.
공개 서버에서 영어·중국어·일본어 각각으로 아이스 바닐라라떼 한 잔을 주문하고
확인 화면까지 진행했으며 모든 경우 동일한 vanilla ID·4,500원을 유지했다.
세 언어의 실제 음성 스트리밍에서 각각 91,200·91,200·153,600바이트의 PCM을
생성했다. 이는 음성 생성 경로 확인이며 전체 발음 품질에 대한 사용자 평가를
대신하지 않는다. 기본 공개 화면에는 언어 선택이 있고 AI 콘솔이 없는 것도 확인했다.

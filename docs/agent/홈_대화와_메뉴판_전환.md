# 홈 대화와 메뉴판 전환

홈에서 채팅을 전송하면 모델 응답을 기다리지 않고 바로 메뉴판을 연다. 추천·주문·옵션 대화를 하는 동안 홈에 남아 있지 않도록 프런트엔드의 실제 화면 전환으로 처리한다. 서버 응답의 menu 뷰도 매장/포장 선택 여부와 독립적으로 반영한다.

매장/포장을 고르지 않았다면 place=null로 전달하고 화면에 ‘매장·포장 선택’을 표시한다. 내부 렌더링용 기본값을 고객의 선택으로 취급하지 않는다. 메뉴 추가 후 새로고침해도 미선택 상태를 보존한다. 이미 선택한 값은 다시 묻지 않고 대화나 화면에서 바꿀 수 있다.

추천 요청은 메뉴판을 보며 먼저 짧게 안내한다. 주문을 시작하거나 마무리하는 적절한 순간에 매장/포장을 확인하고, 결제 전에는 선택을 마친다. 화면으로 결제하기를 눌러도 미선택이면 선택 창을 열고, 선택하면 담긴 주문을 유지한 채 결제수단 화면으로 이어진다.

자동 검증: 첫 추천을 보낸 직후 아직 응답이 도착하지 않았는데도 메뉴판이 보이는지, 후속 주문에서도 홈으로 돌아가지 않는지, 미선택 place=null이 유지되는지, 포장 답변이 반영되는지, 미선택 상태의 수동 결제와 임시 주문 복원을 검증한다. 관련 브라우저 14개 시나리오와 웹 단위 테스트 39개를 통과했다.

공개 AI 키오스크와 실제 모델에서 ‘달달한 뜨거운 커피 추천해줘’를 보낸 직후, 응답이 오기 전부터 메뉴판이 보이는 것을 확인했다. ‘그걸로 줘’로 옵션 확인을 이어 가도 메뉴판을 유지했고, ‘포장이고 추천해준 그 메뉴 한 잔을 나머지는 기본으로’로 카라멜마끼아또 한 잔과 포장 선택이 반영됐다.

# SWitch 창업캡스톤디자인

## Git 버전 관리

`창캡디` 루트에서 키오스크·하드웨어·주문 에이전트 소스와 문서를 하나의 로컬 저장소로 관리합니다. 기본 브랜치는 `main`입니다. 현재 작업 상태를 최초 커밋으로 기록하며 이전 개발 이력을 소급해서 만들지는 않습니다.

- 변경 확인: `git status` / `git diff`
- 이력 확인: `git log --oneline`
- 작업 단위로 관련 파일만 스테이징한 후 `AGENTS.md`의 규칙에 맞춰 커밋합니다.
- `output/`, `tmp/`, `archive/`, 배포용 `public/downloads/`·`public/updates/`, 테스트 결과, 의존성·가상환경·로컬 데이터는 제외합니다. 파일은 디스크에 그대로 남습니다.
- 메뉴 이미지·글꼴·효과음 같은 실행 필수 자료와 잠금 파일은 포함합니다. 생성된 CAD 조각은 원본 설계·생성 스크립트로 다시 만듭니다.
- 원격 저장소는 설정하지 않았습니다. Git 커밋과 키오스크 업데이트 서버 배포는 별도 작업입니다.

실행과 빌드는 각 하위 폴더의 안내를 따르세요. Git에 기록한 것만으로 기능 검증을 마쳤다는 의미는 아니며, 진행 중인 주문 에이전트 코드도 초기 스냅샷에 포함합니다.

앞으로 작업할 폴더입니다. 2026-11-19에 이전 Codex 프로젝트, Downloads, 기존 `창업캡스톤` 폴더의 관련 로컬 자료를 원본 보존 방식으로 모았습니다.

## 마이크 테스트 실행

키오스크 UI 개발은 [실행·수정 안내](kiosk-web/README.md)를 확인하세요. `kiosk-web/키오스크_개발.command` 또는 `npm run dev`로 실행하며 기본 주소는 http://127.0.0.1:5173/ 입니다.

- 버튼을 누를 때만 듣기: [마이크 듣기](hardware/kiosk_audio_monitor/마이크_듣기.command)
- 버튼 없이 음량 2배로 계속 듣기: [마이크 계속 듣기](hardware/kiosk_audio_monitor/마이크_계속듣기.command)
- 배선·업로드·Windows 실행 방법: [오디오 모니터 설명](hardware/kiosk_audio_monitor/README.md)

실행 파일을 동시에 켜지 마세요. 첫 실행 시 이 폴더 아래에 새 Python 가상환경을 만들고 필요한 패키지를 설치합니다. 이전 가상환경과 캐시는 복사하지 않았습니다. 현재 마이크 재생은 종료된 상태입니다.

## 정리 범위

파일 내용은 변경하지 않고 복사했으며, 서로 다른 버전명은 보존했습니다. Downloads와 기존 결과물에서 내용이 완전히 같은 복제본은 한 파일로 통합하고 CSV에 원본 경로를 모두 기록했습니다. 문서의 가격·전략·수치는 작성 시점별 초안일 수 있으므로 최종 확정안과 구분하세요.

이전 문서 제작 스크립트에는 이전 작업 경로 및 도구 의존성이 남아 있을 수 있습니다. 보관용 원본이므로 다시 실행할 때 경로를 먼저 확인해야 합니다. 이전 Codex 프로젝트 전용 `AGENTS.md`는 가져오지 않았습니다.

이번 수집은 로컬 파일 기준입니다. Google Docs의 실시간 문서·댓글을 새로 내려받지는 않았으며, 대화에 첨부되었던 임시 클립보드 이미지 1개는 기존 임시 경로에서 찾지 못했습니다. 린캔버스 완성 이미지와 과제 PPTX는 포함했습니다.

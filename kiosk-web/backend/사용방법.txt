SWitch Windows 오프라인 키오스크

1. ZIP의 압축을 모두 풀어 주세요. ZIP 안에서 실행하지 마세요.
2. Epson TM-m30 드라이버를 설치하고 USB 프린터를 Windows에 등록해 주세요.
3. 실행.bat을 더블클릭해 주세요. 포함된 Python 백엔드와 전용 브라우저가 켜집니다.
   Windows 실행은 전체화면 고정이며 미리보기 도구줄은 표시하지 않습니다.
   테스트용 브라우저 안내 띠도 실행 옵션으로 숨깁니다.
4. 첫 실행은 기기 설정 화면이 열립니다. 실제 프린터 선택 → 자동 출력 켜기 → 설정 저장.
5. 테스트 출력으로 한글·용지·좌우 위치·절단을 확인해 주세요.
6. 주문 → 결제 완료 시 백엔드가 영수증을 만들어 Windows 대기열로 보냅니다.
   출력 대기열 접수 후 완료 화면을 표시하며 5초 뒤 메인으로 돌아갑니다.

설정: 설정.bat 또는 화면에서 Ctrl+Alt+S
주문 이력·관리자 재출력: Ctrl+Alt+H
업데이트: 인터넷 연결 후 업데이트.bat 실행. 변경 파일 검증 → 백업 → 적용 후 종료. 키오스크는 별도로 실행.bat을 실행하세요.
업데이트 중 오류가 발생하면 이전 파일로 복구합니다. 일반 실행에는 인터넷이 필요하지 않습니다.
종료: 종료.bat 또는 백엔드 실행 창에서 Ctrl+C
일반 Chrome이나 다른 프로그램은 종료하지 않습니다.
키오스크 창을 닫아도 백엔드는 실행 창에서 계속 동작할 수 있습니다. 종료.bat으로 종료해 주세요.

필요한 자료: Python·Pillow·실행용 Chrome·메뉴 이미지·Pretendard 글꼴·소스 포함.
Node.js·Python·Chrome을 별도로 설치할 필요가 없습니다. 인터넷 연결도 필요하지 않습니다.
Windows 11 x64 기준입니다. Windows 기본 .NET/PowerShell과 Epson 프린터 드라이버는 필요합니다.
프린터 드라이버의 80mm 롤 용지, 문서 종료 절단 설정을 사용합니다.
설정의 좌우 보정은 -3~+3mm, 기본 글자 크기는 100%입니다.
효과음 12종은 PC 스피커로 재생하며 설정에서 각각 들어보고 음소거·볼륨을 바꿀 수 있습니다.
기본 원음 크기를 높였으며 새 설치의 기본 볼륨은 75%입니다. 기존에 저장한 볼륨과 음소거는 유지합니다.

기본 주소: http://127.0.0.1:18731/
기기 설정·출력 이력·영수증 PNG·로그: %LOCALAPPDATA%\SWitch\Kiosk
장바구니·완료 주문: 전용 브라우저 프로필에 저장.
USB를 뺐다가 다시 꽂았거나 프린터 이름을 바꿨다면 설정의 목록 새로고침 후 다시 선택하세요.

출력 실패·상태 불명에는 자동 재시도하지 않습니다. Windows 대기열을 확인한 뒤
영수증 보기 → 영수증 출력으로 수동 재출력해 주세요. 중복 출력 방지를 위한 동작입니다.
대기열 전송은 실제 종이 출력 완료를 보증하지 않습니다.
결제는 데모이며 실제 카드 승인이나 청구는 발생하지 않습니다.
음성 인식·주문 대화·화면 조작 에이전트는 이 패키지에 아직 포함되지 않습니다.

검증 범위: Mac에서 로컬 주문 흐름·백엔드 API·PNG 렌더링·설정 저장·출력 요청 중복 방지 검증.
실제 Windows 미니 PC에서 USB 출력·한글·자동 절단·터치·효과음 음량은 최종 확인이 필요합니다.

화면에서 종료: 첫 화면(매장/포장)의 오른쪽 맨 위를 5초 안에 연속 5번 누르고 종료하시겠습니까? → 예를 누르세요. 진행 중인 출력·프로그램 정리 후 자동 종료됩니다. 주문 기록과 설정은 유지됩니다.
